## 👨‍💻 About Me

I'm a **DevOps Engineer with 4+ years of experience** designing, deploying, and automating scalable and secure cloud infrastructure on AWS.

My experience includes Infrastructure as Code, CI/CD automation, container orchestration, configuration management, cloud security, and centralized monitoring across multiple environments.

- ☁️ Building and managing AWS cloud infrastructure
- 🏗️ Automating infrastructure with Terraform and CloudFormation
- 🔄 Developing CI/CD pipelines using Jenkins, GitHub Actions, GitLab CI/CD, and Argo CD
- 🐳 Containerizing applications with Docker and orchestrating workloads using Kubernetes (EKS)
- 🔐 Managing IAM, secrets, encryption, and secure cloud configurations
- 📊 Monitoring infrastructure with Prometheus, Grafana, CloudWatch, and other observability tools
- 🚀 Supporting Development, Staging, and Production deployments
- 🎯 Focused on reliability, scalability, automation, and cost-efficient cloud environments
